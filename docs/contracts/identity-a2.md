# A2 身份实现默认值

本文只记录 A2 的实现选择。产品口径以同目录《新用户流程 A1 身份契约（2026-11-25）》v0.1.0-C 为准。阈值、验证码寿命和令牌寿命都不是契约锁定项。

## 状态与短信

验证码摘要、限流计数和幂等记录放在 API 进程内存中，进程重启后清空。账号、建档答案、语言与区号偏好、会话令牌摘要的存放见 `identity-a3.md`。短信不接供应商：默认发送器丢弃验证码，不写日志、不进响应。测试可以注入捕获发送器，或注入只在该进程内生效的发码函数。这两处都不是 HTTP 接口，生产进程不打开它们。

验证码只以 HMAC-SHA256 摘要留在内存。摘要密钥在进程启动时随机生成，不写入仓库、环境样例或日志。

## 默认阈值

| 项 | 默认 |
|---|---|
| 验证码寿命 | 5 分钟 |
| 单条验证码错误次数 | 5 次，用尽后 `AUTH_OTP_MAX_ATTEMPTS`，须重发 |
| 发码成功后的冷却 | 60 秒。成功响应的 `retry_after_seconds` 就是这个冷却 |
| 同一号码发码预算 | 10 分钟内 5 次 |
| 同一来源 IP 发码预算 | 10 分钟内 30 次 |
| 同一号码验码预算 | 10 分钟内 10 次 |
| 同一来源 IP 验码预算 | 10 分钟内 40 次 |
| 访问令牌寿命 | 15 分钟 |
| 刷新令牌寿命 | 30 天。刷新时旋转访问令牌和刷新令牌 |
| 幂等记录寿命 | 24 小时 |
| 幂等键长度 | 1–200 个可见 ASCII 字符 |
| 昵称 | 去掉首尾空白后 1–32 个 Unicode 码位，不含控制字符 |
| 第 2–7 步 `answer` | 任意非空字符串，最长 4096 字节。没有选项目录 |
| 国内号码位数 | 只要求 1–32 位数字，不另造号段规则 |

冷却只在真正发出短信后开始。`AUTH_ACCOUNT_EXISTS` 和 `AUTH_ACCOUNT_NOT_FOUND` 不发短信，也不占用冷却。新的幂等键若撞上冷却或预算，返回 `RATE_LIMITED`，`details.retry_after_seconds` 为剩余等待秒数。同一幂等键加同一请求体只保留第一次结果，不再次发短信，也不再次计数。

`H3` 仍是实施假设，不是已确认产品口径：建档未完成是 `NEED_ONBOARDING`；建档完成但首包步骤未完成是 `NEED_FIRST_PACK`；两件都完成是 `READY_HOME`。身份 HTTP 不写 `has_first_pack`。知识域在首次导入作业进入 `map_ready`，或跳过首包成功时，把它置为 true。测试夹具仍可以直接设置。
