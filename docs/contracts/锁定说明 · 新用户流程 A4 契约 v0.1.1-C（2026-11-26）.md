## 2. 本轮锁住

### 2.1 上一版已锁、本轮保持不变

- 四个已有接口的路径、方法、字段与错误码
- 创建空知识包与导入 `202` 受理不得把 `has_first_pack` 置为 `true`
- 首次 `map_ready` 仍是因导入而置真的写入点（本轮另增「跳过」也可置真，见 2.3）
- 粘贴笔记走材料再导入，并进入 S01，不假装已完成
- 不为抖音 / B 站、ISBN / 书名开 endpoint
- 等待页在作业未 `map_ready` 时不得进默认首页入口
- H3（老用户验码后是否跳过建档与首包）仍是实施假设，不是已锁产品口径
- 不改 A1 已锁路径与身份 schema 的字段 / 枚举（`AccountSummary.has_first_pack` 仍是那个布尔字段，`next_step` 仍是三个值）

### 2.2 产品行为（引已确认 phase B §7.4）

「我没有材料」：**不创建导入作业、不进等待页**，直接走默认首页入口（首页内容本切片不实现）。

### 2.3 写入规则（引本轮 Owner 锁定说明 / 点名要求）

上一版把「跳过如何写入 `has_first_pack`」列为开放项 **A4-O1**。本轮该条升为正文确定结论，**A4-O1 不再作为开放项编号使用**。

锁住的规则：

- 新增专用跳过接口，路径写死为 `POST /v1/knowledge/first-pack/skip`（`first-pack` 为名词资源，`skip` 为资源下的明确子资源，与 A1 的 `/v1/identity/session/revoke` 同类，符合 I03）。
- 需登录；必须带 `Idempotency-Key`，规则与 A1 / 本约导入接口一致。
- 不创建导入作业、不要求先有知识包。
- 不得新增 `next_step` 值；不得让端上本地标志成为权威。
- `has_first_pack` 的含义扩展为「首包步骤已完成」：该学习者首次有导入作业进入 `map_ready`，**或**用户经本跳过接口选择「我没有材料」。含义扩展只写在 A4 知识域写入规则，不改 A1 定稿文件。
- 空包创建与导入 `202` 受理仍不得置真，以免绕过等待页闸门。
- 跳过成功后，首包步骤视为已完成：若建档已完成，`next_step` 为 `READY_HOME`，刷新会话不得打回 P04；若建档未完成，仍可记录跳过，但 `next_step` 保持 `NEED_ONBOARDING`。
- 若已经 `has_first_pack=true`（例如已经 `map_ready` 过）再调跳过：幂等成功，返回 2xx，不把已完成打回未完成，不清除已有知识包或作业。
