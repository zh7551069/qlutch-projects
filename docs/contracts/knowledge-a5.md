# A5 实现说明

本文只记录 A5 的实现选择。产品口径以同目录《新用户流程 A5 worker 契约 v0.1.0-C（2026-11-26）》和《锁定说明 · 新用户流程 A5 契约 v0.1.0-C（2026-11-26）》为准。下面这些仍是开放项，不是已锁口径：H3、A4-O2、A4-O3、A5-O1、A5-O2、A5-O3，以及方案里的免费导入间隔。供应商、温度和费率也不在这里指定。

## 状态

A4 受理仍把作业写成 `accepted` 并入队。工人取出作业后先写成 `running`，S01 成功时先把目录、章节、考点写入知识包，再把 `status` 写成 `map_ready`，并在同一次提交里把该学习者的 `has_first_pack` 置为真。查询看不到「还没有地图的 `map_ready`」。本切片不把 `map_ready` 再迁走。

材料对象缺失，或读到的字节数和申报大小不一致，写成 `failed_terminal`。材料仍完整可读时，S01 失败写成 `failed_retryable`。失败说明是固定短句，不回提供方原文、密钥或材料正文。本轮没有新增 `failure_code`。

`TestingSetJobStatus` 仍只在测试里推进合同状态，不注册 HTTP，生产工人不调用它。

## S01 / S02

生产路径调用 `services/airuntime`。知识域不引用模型供应商 SDK。未安装提供方时，S01 记失败流水并停在 `failed_retryable`，不把作业标成 `map_ready`。

文本按段送入，文档按块送入，一次模型调用只带一块。图片只记 `S01-OCR`，音频只记 `S01-ASR`，粘贴笔记和文档记 `S01-TEXT`。本切片没有书目入口，不记 `S01-META`。同一材料字节和同一模板版本的成功地图可以复用，复用命中单独记账，不再调用提供方。

`map_ready` 提交之后才对当前考点和下一考点做小批量预出题。这一批的规模是实现默认，不是已锁数字，也不是按可配上限出满。S02 使用子类「后台预生成」，不和 S01 或 S05 记在一起。S02 失败不改变作业状态，也不改变 `has_first_pack`。`GET /v1/knowledge/jobs/{id}` 不跑 S01 或 S02。

## 账本

每条 S01 或 S02 流水记下场景码、子类、档位、是否复用、成败、重试序号、token 或对等计量、知识包、作业、模板版本、调用方和时间。调用方是学习者业务。流水只追加。不保存教材原文、完整提示词或单价。未配置费率时不写价格。

## 配置

名称沿用已有的 `QLUTCH_S3_*`、`QLUTCH_WORKER_QUEUE`、`QLUTCH_WORKER_HEARTBEAT`，另读取已有的 `QLUTCH_DATABASE_URL` 和 `QLUTCH_REDIS_ADDR`。本文不写值。
